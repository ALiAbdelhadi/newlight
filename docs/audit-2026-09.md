## 3. تجميع عائلات المنتجات (89 عائلة)

**الاستعلام الأساسي**:
```sql
SELECT members, count(*) as num_families FROM (
  SELECT "baseProductId", count(*) as members FROM products GROUP BY "baseProductId"
) t GROUP BY members ORDER BY members;
```

**النتيجة**:

| عدد الأعضاء | عدد العائلات |
|---|---|
| 1 | 41 |
| 2 | 22 |
| 3 | 8 |
| 4 | 11 |
| 5 | 6 |
| 6 | 1 |
| **المجموع** | **89** |

**ملاحظة مهمة**: لم توجد أي عائلة بها أعضاء بـ `variantType` غير متطابق — كل العائلات متسقة.

**الاستعلام المحقق**:
```sql
SELECT "baseProductId", array_agg(DISTINCT "variantType") as variant_types, count(*) as members
FROM products
WHERE "baseProductId" IS NOT NULL
GROUP BY "baseProductId"
HAVING count(DISTINCT "variantType") > 1;
```
**النتيجة**: صف واحد فقط (0 rows) — لا توجد عدم اتساق.
